# 句幕 Jumu 0.3.3 · Windows x64

下载 `Jumu-0.3.3-win-x64.zip`，解压后运行 `Jumu.exe`。程序自包含，无需另外安装 .NET。

- 新稿件默认将所有文本归为「旁白/人物动作或其他」，保留姓名、引号和标点；需要时可开启「自动识别对白与角色」。旧 `.jumu` 工程继续沿用原来的自动识别行为。
- Windows 可执行文件更名为 `Jumu.exe`，并嵌入句幕图标。
- 修订 Mac 应用名称与图标资源，但本次 Release 仅提供 Windows 下载包。

核心测试 56/56 通过；Windows x64 自包含构建和图标资源检查通过。**尚未在真实 Windows 电脑上运行验证。**请先在稿件副本上试用，检查导出的 `.rpy` 后再用于正式项目。压缩包 SHA-256 见附件 `SHA256SUMS-0.3.3.txt`。
