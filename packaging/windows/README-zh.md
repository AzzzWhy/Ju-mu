# 句幕 Jumu 0.3.3（Windows x64）

解压整个文件夹后，双击 `Jumu.exe`。这是自包含版本，不需要另行安装 .NET。

导入 TXT、DOCX 或 Markdown，或将原文粘贴到左侧，然后点击「解析文本」。新稿件默认全部归为「旁白/人物动作或其他」，原文中的姓名、引号和标点会保留。若希望按规则识别对白、人物和舞台说明，请勾选「自动识别对白与角色」并重新解析。旧版 `.jumu` 工程会沿用原来的自动识别设置。

完成逐句校正与选项树编辑后，点击「导出 .rpy」，将生成的文件放入 Ren’Py 项目的 `game` 文件夹，并从现有入口调用导出的 label。

目前 Windows 包已完成跨平台构建及图标资源检查，但尚未在真实 Windows 电脑上实机验证。遇到问题请附上复现步骤与报错信息。源代码以 MIT 协议开源；第三方依赖见 `THIRD-PARTY-NOTICES.md`。
