# 句幕 Jumu 0.4.3（Windows x64）

解压整个文件夹后，双击 `Jumu.exe`。这是自包含版本，不需要另行安装 .NET。

导入 TXT、DOCX 或 Markdown，或将原文粘贴到左侧，然后点击「解析文本」。新稿件默认全部归为「旁白/人物动作或其他」，原文中的姓名、引号和标点会保留。若希望按规则识别对白、人物和舞台说明，请勾选「自动识别对白与角色」并重新解析。旧版 `.jumu` 工程会沿用原来的自动识别设置。

正文支持多选删除、右键删除和右侧顶部删除按钮，删除前确认，之后可撤销。素材袋存放新建、导入或已校正的完整文本，每份文本是一张卡片，也支持多选删除；被其他分支引用的内容需先解除连接。

选项树「分支结束后」的目标列表优先显示折叠素材和当前正文，直接点击名称即可跳到整份文本；点击 ▸ 展开后可选择内部句子。「更新跳转连接」后，再点「应用选项树」。素材袋内编辑也需「应用素材袋」，最后保存 .jumu 工程。取消窗口不写回，未连接素材草稿不导出。

完成校正与选项树编辑后，点击「导出 .rpy」，将生成的文件放入 Ren’Py 项目的 `game` 文件夹。新项目缺少入口时，可在「角色与导出设置」勾选自动生成 `label start`；已有入口的项目则从入口调用导出的剧情 label，避免重复定义 start。中文字体需在 Ren’Py 项目中单独设置。

核心测试 84/84 通过，macOS 窗口已验证多选/右键删除、撤销、引用保护和折叠跳转选择。Windows 包已完成跨平台构建，但尚未在真实 Windows 电脑上实机验证，且没有数字签名。请先用稿件副本试用；遇到问题请附上复现步骤与报错信息。源代码以 MIT 协议开源；第三方依赖见 `THIRD-PARTY-NOTICES.md`。
